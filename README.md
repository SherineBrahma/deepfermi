# DeepFermi
A deep learning framework for quantifying MR myocardial perfusion

![Static Badge](https://img.shields.io/badge/PyTorch-%23EE4C2C?style=for-the-badge&logo=pytorch&labelColor=black&color=%23EE4C2C)

## Installation

## 1. Clone the repository
2. Create/select a python environment
3. Open the terminal in the "DeepFermi" main folder
4. Install python3.8: ``` conda install python=3.8 ```
4. Install "DeepFermi" in editable mode with linting and testing: ``` pip install -e ".[lint,test]" ```
5. Setup Pre-Commit Hook: ``` pre-commit install ```
